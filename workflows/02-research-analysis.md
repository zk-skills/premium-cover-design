# 流程二：多轮调研分析

> 不允许从文案直接跳到配方。调研的作用不是“找参考图”，而是把主题翻译成可执行的设计变量。

## 硬规则

1. 至少三轮，每轮必须留下书面记录。
2. 第二轮必须带来第一轮没有的新信息（新关键词、新参考、新矛盾），只换同义词不算。
3. 每条调研结论都要落到一个具体设计决策：字体、构图、色彩、材质、信息层级。落不下去的结论直接删。
4. 调研结论与直觉冲突时，先记录冲突，不要急着选边。

## 第 1 轮：主题与读者

**要回答**：这本书在讲什么、给谁看、读者此刻的处境是什么。

**检索对象**

- 书名、副标题里的核心概念（如“品类增长”“三品合一”）
- 作者背景、所在机构、过往作品
- 行业现状、读者痛点、同类方法论
- 出版社会把这本书放进哪个书系、哪类货架

**工具**

- `web_search`：概念、行业、作者、同类书
- `internal_search`：机构内部资料、过往出版物
- `web_fetch`：重点文章、出版社页面、作者访谈

**产出：关键词地图（30 个）**

按五类各收 6 个，不许混类：

| 类别 | 示例 |
| --- | --- |
| 主题词 | 品类、增长、内卷、破局、方法论 |
| 情绪词 | 焦虑、突围、笃定、锋利、克制 |
| 材质词 | 黄铜、宣纸、混凝土、磨砂玻璃、油墨 |
| 时代词 | 当下、传统、未来、档案、手工 |
| 文化词 | 东方、包豪斯、编辑、构成主义 |

**通过标准**：随便抽三个词，都能说出它会影响封面的哪个决定。

## 第 2 轮：视觉与竞品

**要回答**：同类书长什么样、读者已经看腻了什么、空位在哪里。

**检索对象**

- 同类畅销书封面、同出版社书系
- 设计奖年鉴、书店陈列、封面设计案例
- 当前视觉趋势（但不能直接照搬趋势）

**产出：竞品坐标**

画一个二维坐标，把 8–12 本同类书放进去：

- 横轴：传统 ←→ 当代
- 纵轴：克制 ←→ 张扬

标出三件事：

1. 密集区：大家都在做的样子。
2. 空位：坐标上没人占的区域。
3. 禁区：与内容气质冲突的区域（例如严肃方法论却做成成功学大字）。

**通过标准**：能用一句话说清“别人都在做 X，我们做 Y，因为 Z”。

## 从关键词到行业、类型、风格

调研结束前，把关键词翻译成三个设计坐标，缺一列不算完成：

| 关键词 | 设计行业 | 出版物类型 | 候选风格 | 排除理由 |
| --- | --- | --- | --- | --- |
| 品类、增长、破局 | 商业 / 品牌咨询 | 经管方法书 | 瑞士编辑、机构高端、粗野金融 | 文学装帧不解决“战法”的锋利感 |
| 内卷、焦虑 | 社会观察 | 大众商业 | 编辑主义、纪实摄影 | 极简留白会显得轻飘 |
| 黄铜、石材、纸 | 产品设计 / 制造 | 设计方法书 | 材质摄影、构成主义 | 插画会削弱材质的分量 |

行业决定视觉语汇，类型决定信息密度，风格只能从行业与类型的交集里选，不能反过来用风格去找内容。

## 第 3 轮：材料与工艺

**要回答**：这个方向能不能做出来、印出来、在缩略图里看清。

**检索对象**

- 中文字体与西文字体的搭配案例
- 纸张、烫印、UV、专色、模切等工艺
- 同类开本的常见用纸与印色

**产出：可执行清单**

| 项 | 结论 | 限制 |
| --- | --- | --- |
| 字体 | 展示体 / 正文 / 元信息 | 必须本地可得 |
| 色彩 | 主色 / 辅色 / 强调色 | 深色大面积需控制总墨量 |
| 材质 | 纯色 / 纸纹 / 摄影 / 金属 | 位图分辨率 ≥ 300dpi |
| 工艺 | 烫金 / 专色 / UV | 成本与打样周期 |
| 装帧 | 平装 / 精装 / 护封 | 是否留书脊 |

**通过标准**：清单里每一项都能在生成或印刷环节落地。

## 调研记录格式

每条记录写三行，缺一行就不算完成：

```
关键词：品类增长 / 内卷
来源：《…》作者访谈、XX 出版社同类书
影响：标题需要“破局”的动势 → 优先 C02 对角或 C04 压边，不用居中对称
```

## 产出物

1. 30 个关键词的关键词地图。
2. 8–12 本同类书的竞品坐标与空位。
3. 字体、色彩、材质、工艺的可执行清单。
4. 三条设计假设，每条都能被后续方案验证或推翻。

## 常见错误

- 只搜书名，不搜作者和行业，关键词全是同义词。
- 把“高级感”“简约”当结论，这两个词不指向任何设计决策。
- 参考图看太多，最后做出一张拼贴脸。
- 调研与设计脱节，文档写得很长，封面还是默认版式。
