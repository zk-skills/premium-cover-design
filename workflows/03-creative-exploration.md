# 流程三：多轮创意探索

> 创意不是等灵感，是按轮次生产、按标准淘汰。三句话写不清的画面，不要交给代码。

## 硬规则

1. 至少三轮：发散 → 收敛 → 组合。
2. 第一轮必须产生 10 个以上隐喻，其中至少 3 个反常识。
3. 每个方向先用 200 字写出画面，再决定配方与构图。
4. 三个候选必须在构图、字体、手法、署名区里至少两项不同，且署名区至少用到两种原型。

## 第 1 轮：发散（10 个隐喻）

从关键词地图里做随机配对，每次取“一个主题词 + 一个材质词”或“一个情绪词 + 一个时代词”。

**写法**：名词 + 动作，短、具体、可画。

示例（《三品合一》）：

1. 三块材质在同一束光下对齐
2. 三个齿轮咬合成一个齿
3. 三股线拧成一股绳
4. 三个声部合成一个和弦（非视觉）
5. 三枚印章盖在同一处
6. 三种土壤长出一根主干
7. 三块布缝成一件衣服
8. 三条河汇成一个三角洲
9. 三个坐标轴交于原点
10. 三次折叠后成为一张纸（反常识）

**质量要求**

- 至少 3 个不是“三个东西放一起”的字面解释。
- 至少 2 个来自非视觉感官（声音、触感、动作）。
- 至少 1 个能让读者产生“原来如此”的停顿。

**淘汰**：需要两句话以上解释才懂的、本质是字面插画的、无法用现有素材完成的。

## 第 2 轮：收敛（3 个方向）

从 10 个里选 3 个，每个写 200 字画面描述，必须包含六项：

```
方向 A
  隐喻：三块材质在同一束光下对齐
  主体：黄铜、纸、石材三块等大方块
  空间：暗调台面，单侧光，长阴影
  文字：标题压在上方黑区或右下偏心
  材质与光：哑光纸、拉丝金属、粗糙石材
  文字位置：标题与主视觉至少一处重叠或错位
```

**通过标准**

- 只看文字描述，就能想象出画面。
- 三个方向的“主视觉”不是同一种手法。
- 每个方向都能说出它对应内容里的哪句话。

## 第 2.5 轮：案例对照（商业书必做）

读 `knowledge/book-cover-tradeoffs.md`，先判轨道，再做对照。

**判轨**：读者在货架上扫 3 秒，还是被推荐后停留 30 秒？渠道是电商／机场／商超，
还是课程／礼品／专业机构？前者走货架轨（标题 26–40% 短边），后者走气质轨（12–22%）。
商业书三套候选至少一套货架轨、一套气质轨。

**拆解参照案例**（用户提供时）：

```
案例：<文件名>
标题占宽：<实测 %>      单字尺寸：<画布宽的 %>
主副比：<倍数>          底色：<色值 / 色温>
图形：<一句话>          五段结构：<标题/副标题/作者/宣传语/社标的位置>
值得借鉴：<5 条>
不应照搬：<5 条>
```

**八维评分**（每项 0–5，候选与案例各打一次）：
3 秒首读 · 标题权重 · 货架差异 · 溢价感 · 概念独特性 · 品类匹配 · 作者匹配 · 渠道适配。

主推方案必须在「3 秒首读」与「溢价感」两项同时 ≥ 3 分；若一项低于 3，换轨道重做。

## 第 3 轮：组合（3 套完整方案）

给每个方向配两套构图与字体，交叉测试后选出最佳组合，形成三套完整方案。

每套写清：

```
方案 1
  隐喻：三块材质在同一束光下对齐
  配方：H17 Brutalist Finance
  构图：C01 满版出血（重心下移，留白 8%）
  字体：T09 暗调反白（思源黑 200 / 字距 0.08em）
  署名区：A03 图文咬合｜题眉 inline｜作者名 700 + 角色词 400
  色彩：近黑 #08080A / 米白 #F2EDE3 / 暗金 #C7A66A
  元素：AI 生成材质图 + 细线 + 反白 Logo
  预期气质：克制、昂贵、有分量
```

**差异检查**

- 三套的构图原型不能相同。
- 三套的字体组合不能相同。
- 三套的主视觉手法不能相同（摄影 / 几何 / 纯文字 / 插画）。
- 三套的署名区至少两种原型，差异要能一句话说清（「一套底栏、一套咬合、一套印戳」）。
- 如果两套只是换配色，合并或重做。

## 产出物

1. 10 个隐喻的清单（标注哪三个反常识）。
2. 3 个方向的 200 字画面描述。
3. 轨道判定卡（气质轨／货架轨 + 渠道依据）。
4. 案例拆解表与八维评分（有参照案例时）。
5. 3 套完整方案卡，字段齐全（含署名区 A0x 与题眉位置），至少覆盖两轨（商业书）。
6. 一句淘汰理由：为什么另外 7 个隐喻不成立。

## 常见错误

- 第一轮就写“高级感、极简、留白”，这些是形容词，不是隐喻。
- 10 个隐喻其实是同一个意思换十种说法。
- 先写代码再想画面，最后靠调色救场。
- 三个方案都绕着同一个构图转。
