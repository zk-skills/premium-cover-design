# 流程一：接收需求与内容分析（第 1 步）

在选择任何风格、搜索任何参考之前，先把需求和内容读懂。

## 0. 需求接收清单

先收齐这八项，缺一项就写进缺口清单并向用户确认：

| 项 | 示例 | 缺失的影响 |
| --- | --- | --- |
| 主标题 | 三品合一 | 无法判断字数与断行 |
| 副标题 | 破局内卷的品类增长战法 | 层级无法建立 |
| 作者 / 组编 | 贾伟 著 / 洛可可品类增长学园 组编 | 页脚缺主角 |
| 宣传语 | 贾伟最新力作！ | 缺少销售信息 |
| 出版社与 Logo | 机械工业出版社 | 无法完成正式封面 |
| 开本与用途 | 180×240mm 书籍 | 画布与出血无法定 |
| 目标读者 | 经管读者、设计师 | 气质与信息密度无从判断 |
| 交付格式 | HTML / PDF / PNG | 导出方式不确定 |

## 1. 抽取五个属性

| 属性 | 要回答的问题 | 用途 |
| --- | --- | --- |
| 主题 | 这份出版物到底在讲什么？ | 决定视觉隐喻 |
| 核心观点 | 读者读完记住的一句话是什么？ | 决定标题层级与字数 |
| 情绪 | 冷静 / 紧张 / 温暖 / 肃穆 / 先锋 / 治愈？ | 决定配方类别 |
| 目标读者 | 谁会买它？专业人士还是大众？ | 决定信息密度与术语 |
| 内容属性 | 报告 / 书籍 / 杂志 / 诗集 / 年报 / 白皮书 / 科普？ | 直接查映射矩阵 |

## 2. 归入内容类型

把内容属性映射到 `knowledge/content-style-mapping.md` 的 15 类之一（文学散文、哲学思想、诗歌情感、历史传记、商业研究、行业报告、科技白皮书、AI 研究、数据报告、自然健康、科学教育、艺术设计、社会议题、建筑城市、生活方式）。

**若内容横跨两类**（例如「面向大众的科技年度报告」= 行业报告 + 科技白皮书），选定一个<strong>主类型</strong>并记录另一个作为「辅助类型的视觉手法参考」，不要把两套风格平均融合。

## 3. 判定标题实长

中文标题的实际长度直接决定版式，必须在这一步量出来：

- ≤ 8 字：可做超大标题（L03），一行或两行解决。
- 9–16 字：常规标题尺寸，可用非对称网格（L01）或分割布局（L06）。
- 17–24 字：需缩小字号或换行控制，优先模块网格（L07）、图文重叠（L13）。
- \> 24 字：先考虑改写标题。封面不是摘要页，容纳不了长句。

同时确认：
- 标题是否含英文/数字混排（会影响字重与字距处理）。
- 副标题是否必要（多数封面有副标题反而削弱标题）。

## 4. 信息缺口清单

把不确定的信息逐条列出：

```
缺口 1：目标读者是创业者还是设计师？→ 影响标题的锐度与图像选择
缺口 2：是否需要留书脊？→ 影响画布宽度与边距
缺口 3：Logo 是否有矢量文件？→ 影响印刷精度
```

缺口超过三项时，先确认再进入第 2 步。

## 5. 产出物

写下一段 100 字以内的内容摘要，包含：主题、核心观点、情绪、读者、内容类型、标题实长判断、候选视觉隐喻 1 个。后续所有步骤以这段摘要为准。

## 常见错误

- 先想风格再想内容 → 风格与主题脱节，封面漂亮但无用。
- 把目录/摘要当成标题写进封面。
- 忽略英文标题与中文标题的字面宽度差异（英文小写 x-height 低，中文方块字面高，同字号下中文视觉更重）。
