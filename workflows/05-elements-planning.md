# 流程五：元素决定

> 先决定“用什么”，再决定“怎么排”。元素错了，版式再准也救不回来。

## 1. 主视觉从哪来

**按这个顺序选，不跳级：**

| 优先级 | 来源 | 适用 | 要求 |
| --- | --- | --- | --- |
| 1 | 生成图像 | 几乎所有正式封面：材质、静物、空间、概念摄影 | 无文字；单个可命名主体；有材质与光；≥150dpi 屏幕 / ≥300dpi 印刷 |
| 2 | 实拍摄影 | 人物、建筑、产品、纪实 | 版权清晰，构图可裁切 |
| 3 | 纯文字 | 概念、文学、宣言、极简 | 字体本身必须足够有性格 |

生成图怎么做，读 `knowledge/hero-image-prompts.md`。一句话：写死主体、材质、光、镜头、留白，缺一项就重出。

**硬规则**：

- 一张封面只有一个主视觉。第二个视觉元素只能是配角，面积不超过主视觉的 30%。
- 用「线段 + 空心方块 + 虚线圆」拼出来的图形不能充当主视觉。它是线框稿，不是封面。
- 主视觉必须经过裁切、叠色、降饱和或重新生成中的至少一步，才能上版。

## 1.5 形状语言

先读 `knowledge/shape-language.md`，决定这张封面是几何、有机还是混合。

| 语言 | 词汇 | 适用 |
| --- | --- | --- |
| 几何 | 矩形、正圆、斜线、严格网格 | 报告、数据、机构 |
| 有机 | 手绘曲线、流体、墨迹、撕裂边、织物褶皱 | 商业方法、社会议题、文学 |
| 混合 | 硬边标题 + 曲线主视觉；网格 + 一处手绘 | 大多数商业书 |

**硬规则**：

- 至少一个非正交或有机元素：曲线、斜切、3–8° 旋转、椭圆裁切、撕裂边、透镜相交。
- 每个形状要有功能：指向、包裹、分割、合并、承托。找不到功能的删掉。
- 一张封面最多两种形状语言。社标保持水平；署名可竖排（A04/A05），但不得旋转整块文字。
- 全正交网格必须有理由（年鉴、法律文本、严格数据报告），并写进 `notes.md`。

产出：形状语言决策卡（主语言 + 非正交手法 + 功能 + 放弃的方案）。

## 2. 背景

| 类型 | 何时用 | 风险 |
| --- | --- | --- |
| 纯色 | 标题或图形是主角 | 容易显得空，需要靠字号与留白撑 |
| 纸纹 | 文学、档案、手工感 | 纹理过强会脏，不透明度控制在 5% 以内 |
| 摄影满版 | 图像本身有叙事 | 文字压亮部会失去可读性，必须加 scrim |
| 渐变 | 货架轨暖底、光晕，且必须有结构理由（相交＝合并、地平线＝增长） | 最易出现“模板脸”；无理由的粉橙渐变删掉；最浅处对比须 ≥4.5:1 |

## 3. 图形与装饰

允许：

- 一条有功能的分割线（区分信息层）。
- 一个与主题有关的辅助图形，面积不得超过主视觉的 30%。
- 一条有功能的曲线、斜切或透镜相交（承托标题、切分版面、表达合并）。
- 一个重复的纹理或网格。

禁止：

- 无来源的英文、编号、坐标、日期。
- 与主题无关的箭头、圆点、波浪线。
- 三种以上装饰同时出现。
- 为了「不规矩」而无理由旋转标题或整块文字。

**数量上限**：装饰元素不超过 3 个，且至少 1 个承担信息功能。

## 4. 文字

在排版前逐项确认：

- 书名断行位置：按语义断，不按字数硬断。
- 副标题字数：超过 16 字考虑精简。
- 作者、宣传语、出版社的字号层级：不得与书名接近。
- 署名区：从 A01–A05 选一种，写清它和标题或主视觉的关系（见 `knowledge/credits-system.md`）。
- 题眉：auto / side / topright / inline，不能默认左上角。
- 角色词：著 / 编著 / 主编 / 绘 / 译 按真实身份写，字号比姓名小 20–40%。
- 中文字距：黑体收紧、宋体微松、细体中文不超过 0.10em。
- 竖排：仅文学与传统文化，且整块靠右；社标不竖排。
- 英文混排：单独设置字距与基线。

## 5. 色彩

- 主色 1 个、辅色 1 个、强调色 1 个，最多再加 1 个中性色。
- 强调色面积不超过 15%，且只出现在需要被记住的位置。
- 深色大面积实地要确认印刷总墨量与发灰风险。
- 金色、银色用四色模拟时，避免脏黄。

## 6. 清晰度

每一张位图都要算，不靠肉眼。

```
有效 dpi = 源像素宽 ÷ (成品显示宽 mm ÷ 25.4)
放大倍数 = 画布显示宽（CSS px） ÷ 源像素宽
```

| 素材 | 印刷最低 | 理想 | 放大上限 |
| --- | --- | --- | --- |
| 主视觉 | 300dpi | 350dpi | 1.5×，>2× 不接受 |
| Logo | 600dpi 等效 | 矢量 | 2× |
| 作者头像／小图 | 300dpi | 350dpi | 1.5× |
| 纹理 | 300dpi | 350dpi | 1.5× |

处理顺序：找原始文件 → Logo 与图标优先矢量重绘 → 按成品尺寸重出 → 裁切不拉伸 → 轻度锐化 → 打样。

工具：

```bash
# 主视觉：裁切 + 调色 + 算 dpi，一步到位
python tools/prepare_hero.py hero-raw.png --size a4 --out hero.jpg \
  --focus "50% 35%" --desat 15 --tone "#0B1A2E" --tone-op 0.28

# Logo：按标识标准单独算
python tools/check_image_quality.py logo.png --mm 50 --display-px 374 --logo
```

结果写进 `notes.md` 的清晰度表。没有这张表，视为未检查。

## 7. 版权与工艺

- 字体：确认可商用或已内嵌。
- 图片：确认授权范围，生成图注明模型与日期。
- Logo：使用官方文件，不描摹、不改色（反白需用官方反白版）。
- 印刷：出血 3mm、安全区、专色、烫印区域提前标注。
