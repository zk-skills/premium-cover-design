# 流程三·补充：封面概念卡（第 3 步第 2–3 轮）

> 发散与收敛的完整方法见 `03-creative-exploration.md`。本文件只负责把选定的方向写成方案卡。

目标是产出<strong>三个真正不同</strong>的方案（约束第 6 条），而不是同一版式换三套配色。

## 1. 差异性从哪来

三个方案必须在下列三项中至少有两项不同：

| 维度 | 取值示例 |
| --- | --- |
| 艺术方向 | 瑞士编辑 / 日式文学 / 数据智能 / 观念艺术 |
| 构图重心 | 满版 / 极限留白 / 中心对称 / 偏心 / 放射 |
| 表现手法 | 几何图形 / 摄影 / 插画 / 线稿 / 三维 / 拼贴 |

## 2. 每个方案必须写清

```
方案 A
  配方：R14 Technology Editorial
  构图：C01 满版出血（重心在下，留白 8%）
  字体：T09 暗调反白（思源黑 200 / 字距 0.08em / 行高 1.1）
  隐喻：透明玻璃体互相嵌套（智能体协作）
  画面：底部满版深蓝玻璃层，标题以超细无衬线压在画面之上
  信息层级：书名 1.0 / 副标题 0.24 / 作者 0.1 / 出版信息 0.06
  预期气质：冷静、精密、可信
```

## 3. 先写画面描述，再写代码

在写 HTML 之前用文字把封面描述出来（200 字内）。如果文字描述已经成立，代码只是复现；如果文字都说不清，代码出来一定散。

## 4. 主视觉的两种来源

1. **生成图像或实拍**：所有正式封面的默认选择。按 `knowledge/hero-image-prompts.md` 写提示词，画面必须落到一个可命名主体、一种材质、一束光。
2. **纯文字封面**：极限留白、超大标题、概念艺术类配方可完全不用图像，此时靠字体与色彩成立，生成时传 `--text-only`。

## 5. 自检三个方案

- 只看标题，能否分辨出是哪个方案？（说明差异成立）
- 三个方案的字体组合与构图原型是否不同？（只换配色不算）
- 三个方案的标题字号差异是否明显？（若雷同，说明版式没拉开）
- 有没有哪个方案只是「另一个方案的备用配色」？有就重做。
- 每个方案跑一次 `score_cover.py`，低于 70 分的方案直接淘汰。

## 5.1 组合方案作为第三个方向

当单一配方无法覆盖主题时，第三个方向优先用组合方案（`--hybrid Hxx`），它天然具备「同一主题的另一种调性」，差异度比换配色大得多。

## 6. 产出物

三张方案卡（各含配方、布局、隐喻、画面描述、层级、气质），交由用户或自评选定其一进入 HTML 生成。
