# 流程四·五：文本介质分配

> 先决定每段文字“要长成什么样”，再决定“用什么做”。
> 不是所有文字都用 HTML，也不是所有文字都转曲。介质由样式需求倒推。

## 1. 列出全部文本元素

封面上的文字不止标题。先把清单列全，再谈介质：

| 类别 | 元素 |
| --- | --- |
| 主信息 | 书名、副标题、宣传语、系列名、卷次 |
| 署名 | 作者、译者、编者、组编机构 |
| 出版 | 出版社中英文、Logo、年份、版次、ISBN |
| 辅助 | 引文、数据标注、图注、英文副题、装饰性大字 |

漏掉任何一项，后面都会返工。

## 2. 为每个元素写样式需求

每段文字都要回答下面六问，答不上来的先别做：

1. **层级**：书名 / 副标题 / 署名 / 出版信息，四级以内。
2. **可改性**：客户会不会改字？会不会换语言？
3. **质感**：实色就够，还是要金属、纸张、石材、光影、3D？
4. **形变**：需要描边、渐变、透视、扭曲、逐字错位吗？
5. **空间关系**：要不要压图、裁切、被图像穿过、做遮罩？
6. **印刷要求**：是否需要矢量？最小成品字号多少？

## 3. 介质判定树

按顺序问，第一个“是”就是答案：

```
这段文字会不会被频繁修改？
  ├─ 是 → HTML 文本（M1）
  └─ 否 ↓
需要真实材质、光影、3D、书法笔触吗？
  ├─ 是 → 图片化（M4），或用 SVG 做图片填充（M2）
  └─ 否 ↓
需要描边、渐变、任意缩放、矢量印刷吗？
  ├─ 是 → SVG 转曲（M2）
  └─ 否 ↓
需要程序化噪点、粒子、扫描线、逐字变形吗？
  ├─ 是 → Canvas（M3）
  └─ 否 ↓
需要与图像咬合、裁切、镂空、遮罩吗？
  ├─ 是 → SVG 遮罩（M2）或 CSS 裁切（M5）
  └─ 否 → HTML 文本（M1）
```

## 4. 五种介质的边界

| 介质 | 能做 | 不能做 | 交付形态 |
| --- | --- | --- | --- |
| HTML 文本 | 字族、字重、字号、字距、行高、颜色、竖排、简单阴影 | 精确矢量描边、材质填充、逐字变形 | 可编辑文本 |
| SVG 转曲 | 描边、渐变、图片填充、遮罩、裁切、逐字变换、任意缩放 | 改字需重新生成；复杂滤镜性能差 | 内嵌 SVG |
| 图片 | 真实材质、摄影合成、3D、书法、复杂光影 | 小字会糊；改字需重做图 | PNG/WebP，≥300dpi |
| Canvas | 程序化纹理、粒子、逐字路径变形、动态 | 不可选中；印刷需导出位图 | Canvas + 导出 PNG |
| CSS 混合 | 图片填充文字（background-clip）、混合模式、简单裁切 | 跨端一致性差；印刷分辨率受限 | HTML + CSS |

## 5. 混合原则

1. 一张封面最多两种文本介质，主标题一种、其余一种。
2. 主标题用 SVG/图片时，副标题、署名、出版信息回到 HTML，保证可读和可改。
3. 同一层级不要混介质：副标题用 HTML，就不要有一段副标题用图片。
4. 小字（≤14px 成品）一律 HTML，不用图片。
5. 需要印厂改字或本地化的部分，一律 HTML。

## 6. 产出：文本介质分配表

写进 `brief.md`，格式如下：

| 文本 | 内容 | 层级 | 样式需求 | 介质 | 理由 | 交付 |
| --- | --- | --- | --- | --- | --- | --- |
| 书名 | 三品合一 | 1 | 哑光金属、矢量、可放大 | M2 SVG | 材质与黄铜块呼应，印刷需矢量 | 内嵌 SVG |
| 副标题 | 破局内卷的品类增长战法 | 2 | 细黑、可改字 | M1 HTML | 需要可读可改 | 文本 |
| 宣传语 | 贾伟最新力作！ | 3 | 金色、小字 | M1 HTML | 可改，小字不用图片 | 文本 |
| 作者/组编 | 贾伟 著 / 洛可可… | 3 | 中性、可改 | M1 HTML | 署名必须可改 | 文本 |
| 出版社 | 机械工业出版社 | 4 | 官方标志 | 图片 | 必须用官方 Logo | PNG 内嵌 |
| 英文社名 | CHINA MACHINE PRESS | 4 | Logo 自带 | 图片 | 与 Logo 一体 | PNG 内嵌 |

## 7. 反模式

- 整张封面全是 HTML 文本，标题只靠改字重，结果平庸。
- 所有文字都转曲，客户改一个字就要重做全套。
- 用图片做 12px 的小字，印刷糊成一片。
- 用 Canvas 做正文，不可选中、不可搜索、印刷不稳定。
- 用 `background-clip:text` 做需要印刷的大标题，分辨率不够。
- 主标题用图片、副标题也用图片、作者还用图片，改一次错一次。

## 8. 与前后步骤的衔接

- 第 4 步定层级与字号，本步定每段文字的介质。
- 第 5 步按分配表准备素材：SVG 路径、图片、Canvas 脚本、HTML 文本。
- 第 6 步生成时，按分配表逐项实现，不临时改介质。
