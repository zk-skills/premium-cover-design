# 流程二：艺术方向选择

## 1. 只读需要的配方

不要把 26 套配方全部载入上下文。先用映射矩阵定位，再只读命中的 1–2 套 `knowledge/design-recipes.md`。

## 2. 主风格选定规则

主风格必须<strong>单一明确</strong>。判断依据按优先级：

1. **气质匹配**：配方「设计定位」一栏的情绪词是否与内容情绪一致。
2. **媒介可行**：配方的「表现手法」在当前项目里能否拿到素材。摄影类配方若没有可用照片，不应硬选。
3. **受众匹配**：专业读者与大众读者对「实验性」的容忍度差异很大。
4. **系列一致性**：成系列出版时，同系列必须锁定同一配方族。

## 3. 何时叠加混合风格

只在普通配方难以覆盖主题时叠加，且遵守：

- 主风格决定调性、色彩体系与材质。
- 辅助风格只贡献<strong>一个具体手法</strong>（例如「精密线稿」「套色偏移」「数据节点」），不参与调性决策。
- 混合后检查：能否用一句话说清「主风格 + 辅助手法」？说不清就不要混。

`knowledge/style-combinations.md` 的 18 套是已验证的组合，直接优先选用；H01–H12 来自原始配方文档，H13–H18 为补齐缺口的扩展组合。

组合方案带可执行手法，可直接产出成品：

```bash
python tools/generate_cover.py --hybrid 13 --title "…" --out cover.html
```

主风格提供色板与版式骨架，辅助风格按需提供主视觉手法 / 纹理 / 展示字体，组合自带推荐布局。

## 4. 排除不适合的配方

以下情形直接排除候选：

- 配方要求的素材类型项目内拿不到（除非改为纯文字方案）。
- 配方字体方向与项目既有字体系统冲突且无法覆盖。
- 配方的情绪与内容相反（用粗野主义做童书、用诗意极简做金融年报）。
- 配方与系列内其他封面冲突。

## 5. 确定视觉隐喻

主风格定调之后，从配方「参考示例」中找同类隐喻逻辑，替换成本次内容的主体：

- 报告类 → 几何结构、数据形态、抽象系统。
- 文学类 → 自然意象、时间痕迹、单一物件。
- 科技类 → 三维结构、透明材质、节点网络。

隐喻必须是<strong>可画出来</strong>的：能用一个物体/场景/结构说清，而不是只能用一句比喻描述。

## 6. 产出物

- 主风格：`<编号> <中文名>` + 选它的理由（一句话）。
- 辅助风格（如有）：`<编号> <中文名>` + 只借用的那一个手法。
- 视觉隐喻：具体到「一个可绘制的主体」。
- 配色方向：底色 / 主墨色 / 强调色三色的初步倾向。
