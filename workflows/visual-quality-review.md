# 流程六：视觉质量评审

评审不是主观打分，而是**可复现的实测**。`tools/verify_cover.py` 已实现 12 项；人工评审按同样口径补齐机器测不到的部分。

## 一、自动门禁（12 项）

```bash
python tools/verify_cover.py cover.html \
  --recipe R01 --title "标题原文" --subtitle "副标题原文" \
  --kicker "题眉原文" --meta1 "机构原文" --meta2 "年份原文"
```

| # | 检查项 | 判定依据 | 不达标时 |
| --- | --- | --- | --- |
| 1 | 文字对比度 | 墨/底 ≥ 4.5:1，强调/底 ≥ 3:1，辅助/底 ≥ 3:1 | 换配色体系，不要只调一两个值 |
| 2 | 缩略图可读性 | 240px 宽下标题 ≥ 8px | 提高标题字号权重或换配方 |
| 3 | 装饰噪音 | 英文与编号必须来自输入 | 删掉来源不明的装饰 |
| 4 | 信息层级 | 3–4 级字号 | 合并层级，别做信息页 |
| 5 | 配方契合 | 令牌与配方一致 | 恢复配方令牌，或明确记录偏离理由 |
| 6 | 画布一致性 | `@page` 与画布尺寸对应 | 对齐预设 |
| 7 | 外部资源 | 只允许字体 CDN | 移除其他外链，字体保留 |
| 8 | 结构完整性 | 四槽位齐全 | 补齐 |
| 9 | 字体栈 | 展示体为在线字体库中的字体 | 换成 `fonts-online.json` 里的字体 |
| 10 | 标题溢出 | 标题与容器均在画布内 | 用 `--fit`，或换宽松布局 |
| 11 | 安全区 | 文字块在 5.5% 裁切风险区内 | 移进安全区 |
| 12 | 主次关系 | 标题块占版面 ≥ 3%，不被主视觉压过 | 放大标题或缩小主视觉 |

## 一·五、视觉表现评分（建议 ≥70）

```bash
python tools/score_cover.py cover.html
```

| 维度 | 不及格信号 | 处理 |
| --- | --- | --- |
| 层级落差 | 书名/副标题 < 2.2 | 缩小副标题，不要放大书名 |
| 标题权重 | 书名占短边 < 10% | 换 C04 / C08 或提高 `--scale` |
| 字体气质 | 未选 T 组合，仍是默认 700 | 从 `type-pairings.md` 选一组 |
| 构图张力 | 只用 L01 / L02 基础网格 | 换 C 原型，或至少做偏心 |
| 克制度 | 颜色 >5、焦点 >3 | 删元素，不要加遮罩 |

## 一·六、商业书双轨复核

先判轨道，再用对应阈值。规则见 `knowledge/book-cover-tradeoffs.md`。

```bash
python tools/score_cover.py cover.html --track premium   # 气质轨
python tools/score_cover.py cover.html --track mass      # 货架轨
python tools/shelf_test.py cover*.png --out shelf.png    # 240px / 120px 首读
```

| 检查 | 气质轨 | 货架轨 |
| --- | --- | --- |
| 单字占画布宽 | 12–22% | 26–40% |
| 240px 书名高度 | ≥ 16px | ≥ 26px |
| 标题墨量（字形覆盖） | 6–14% | 14–30% |
| 主副字号比 | ≥ 2.2 | ≥ 3.0 |
| 社标宽度 | ≥ 18% | ≥ 22% |
| 五段全居中 | 需有偏心元素 | 标题须 ≥ 30% 宽 |
| 渐变最浅处对比 | ≥ 4.5:1 | ≥ 4.5:1 |

三套候选必须覆盖两轨；只做一轨时，在结论里写明渠道依据。

## 一·七、形状与清晰度

形状语言按 `knowledge/shape-language.md` 人工核对：

- [ ] 至少一个非正交或有机元素（曲线、斜切、3–8° 旋转、椭圆裁切、撕裂边、透镜）。
- [ ] 这个元素有功能，不是装饰。
- [ ] 形状语言不超过两种；标题与社标保持水平，署名竖排仅限 A04/A05。
- [ ] 署名区与题眉不是默认底栏；三套候选至少两种署名原型（见 `credits-system.md`）。
- [ ] 社标没有压图无底、没有被裁切，宽度满足轨道要求。
- [ ] 缩到 240px 后，形状仍能看出意图。

清晰度逐张算，不靠肉眼：

```bash
python tools/check_image_quality.py hero.png --mm 141 --display-px 1060
python tools/check_image_quality.py logo.png --mm 50 --display-px 374 --logo
```

| 素材 | 印刷最低 | 理想 | 放大上限 |
| --- | --- | --- | --- |
| 主视觉 | 300dpi | 350dpi | 1.5×，>2× 失败 |
| Logo | 600dpi 等效 | 矢量 | 2× |
| 小图／纹理 | 300dpi | 350dpi | 1.5× |

结论写进 `notes.md`，没有表视为未检查。

## 二、人工复核（机器测不到的部分）

| 维度 | 要回答的问题 |
| --- | --- |
| 语义 | 主视觉是否真的指向主题，而不是一个通用装饰？ |
| 气质 | 整体感受是否符合内容情绪（冷静的报告不应躁动）？ |
| 视觉噪音 | 装饰线、编号、边框是否在争夺注意力？ |
| 署名区 | 作者、组编、社标是否只是被放在角落？与标题或主视觉有什么关系？ |
| 形状 | 是否全是正交矩形？曲线／斜切／旋转是否有功能，而不是为了不规矩？ |
| 系列统一 | 与同系列其他封面的配色、字体、主视觉语言是否一致？ |
| 印刷可行性 | 深底大面积实地 + 高对比小字是否导致偏色或糊版？ |
| 隐喻质量 | 视觉隐喻是否优于字面插画（约束第 2 条）？ |

## 三、三方向差异复核

- 只看标题，能否分辨出是哪个方案？（差异成立）
- 三个方案的字体组合与构图原型是否不同？
- 三个方案的标题字号差异是否明显？（若雷同，版式没拉开）
- 有没有哪个方案只是另一个方案换配色？（有就重做）

## 四、评审结论写法

```
风格版式：R12 机构高端 × C08 极端偏心 × T02 文学宋 × M2 转曲｜气质轨
形状语言：几何 + 有机（立方体 + 竖排），无斜切；靠偏心与出血制造张力
清晰度：主视觉 288dpi（0.66×）；Logo 448dpi 位图，建议换官方矢量
轨道：气质轨（渠道：地面店 / 礼品；读者停留 30 秒）
门禁：12/12 通过
  对比度 16.74:1（墨/底）· 4.44:1（强调/底）
  缩略图标题 25.2px @240px
  安全区：全部文字块在内
  主次关系：标题块占 18.4%
  层级：4 级
商业书附加：B1–B6 通过（单字 16.4% / 主副比 6.0 / 社标 27.7%）
表现：86/100（层级 20 · 标题 20 · 字体 20 · 构图 20 · 克制 6）
人工复核：语义指向主题；无装饰噪音；可印刷
```

## 五、交付消息（必须包含）

最终回复不能只丢链接。第一行写风格版式组合，第二行写清晰度，再给文件链接：

```
风格版式：<Rxx 配方> × <Cxx 构图> × <Txx 字体> × <Mx 介质>｜<气质轨/货架轨>
清晰度：主视觉 <dpi>dpi（放大 <倍数>）；Logo <矢量/位图 dpi>
```

示例：

```
风格版式：R12 机构高端 × C08 极端偏心 × T02 文学宋 × M2 转曲｜气质轨
清晰度：主视觉 288dpi（0.66×）；Logo 448dpi 位图，建议换官方矢量
```

如果做了多套，逐套列出；货架轨另标 `--track mass`。
