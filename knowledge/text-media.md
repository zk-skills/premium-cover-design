# 文字介质与表现手法

> 标题不是一段文字，是封面里面积最大、最先被看见的图形。
> 只改字体、字号、字重，最多做出“排印”；换介质，才能做出“表现”。
> 具体某段文字该用哪种介质，先走 `workflows/04-text-allocation.md` 的判定树，再回本文件选手法。

## 六种介质

| ID | 介质 | 本质 | 什么时候用 | 代价 |
| --- | --- | --- | --- | --- |
| M1 | HTML 文本 | 可编辑的文字 | 报告、白皮书、需要频繁改字 | 受客户端字体限制 |
| M2 | SVG 转曲 | 矢量图形 | 书籍主标题、艺术/设计/材质类 | 改字需重新生成 |
| M3 | Canvas 渲染 | 程序化图像 | 噪点、渐变、逐字变形、动态纹理 | 印刷需 300dpi 导出 |
| M4 | 图片化文字 | 位图/合成图 | 3D、光影、实拍材质、书法 | 分辨率与版权 |
| M5 | 裁切/遮罩 | 文字作为窗口 | 冲击力、图文咬合、负空间 | 可读性风险 |
| M6 | 混合介质 | 主标题 SVG + 副标题 HTML | 大多数正式书籍 | 需要层级控制 |

选择顺序：先看主题是否需要“材质感”。需要 → M2/M4；不需要 → M1；要冲击 → M5；要动态/纹理 → M3。

## 十八种表现手法

### 排印层（M1）

1. **细体大字**：200–300 字重，字距 0.08em，高端克制的默认解。
2. **超粗压边**：800–900 字重，负字距，标题接近出血。
3. **竖排**：`writing-mode:vertical-rl`，仅文学、传统文化。
4. **单字放大**：关键字放大 1.5–2 倍，其余字缩小，制造停顿。
5. **字距呼吸**：逐字增加或减少字距，形成节奏。
6. **基线跳动**：每个字上下错开 2%–6%，适合轻松、青年题材。
7. **印章反白**：方块底色内放反白字，适合系列标识、卷次。

### 图形层（M2）

8. **描边镂空**：`fill:none` + 1–3px 描边，背景材质透出，当代、克制。
9. **金属渐变**：线性渐变从亮金到暗铜，注意不要做成成功学。
10. **材质图片填充**：把文字当窗口，内部透出黄铜、石材、纸张。
11. **叠印偏移**：主字下方偏移一层强调色，形成印刷错版感。
12. **单字旋转**：一个字旋转 5°–12°，打破机械感，只转一个。
13. **重复字形**：同一句重复成纹理，适合背景，不可当主标题。
14. **文字遮罩**：用文字裁切图片，图像只在笔画内可见。

### 空间层（M5）

15. **裁切出血**：标题超出画布，被边缘切掉 10%–20%，必须保留可识别的主体笔画。
16. **图文咬合**：标题压在图像边缘，一半在图上、一半在纯色区。
17. **负空间字**：大色块中挖出字形，字是“空”的，不是“实”的。

### 程序层（M3）

18. **Canvas 纹理/噪点**：用 Canvas 给字形加颗粒、扫描线、渐变噪声，需导出位图。

## 工具

`tools/text_to_svg.py` 把文字转成矢量路径，支持：

```bash
# 金属渐变
python tools/text_to_svg.py --text "三品合一" \
  --font /usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc --font-index 2 \
  --size 240 --gradient "#E8D5A8,#6E5228" --output hero.svg

# 描边镂空
python tools/text_to_svg.py --text "三品合一" --font <字体> --font-index 2 \
  --size 240 --fill none --stroke "#F2EDE3" --stroke-width 2.4 --output hero.svg

# 材质图片填充
python tools/text_to_svg.py --text "三品合一" --font <字体> --font-index 2 \
  --size 240 --image brass.jpg --output hero.svg

# 叠印偏移
python tools/text_to_svg.py --text "三品合一" --font <字体> --font-index 2 \
  --size 240 --fill "#F2EDE3" --offset-shadow "#E8112D" --shadow-dx 12 --shadow-dy 12 --output hero.svg

# 单字旋转
python tools/text_to_svg.py --text "三品合一" --font <字体> --font-index 2 \
  --size 240 --fill "#F2EDE3" --rotate -9 --rotate-index 3 --output hero.svg
```

输出 SVG 可直接内嵌封面 HTML，印刷为矢量，不依赖客户端字体。

转曲需要本地字体文件：系统字体在 `/usr/share/fonts/opentype/noto/`，TTC 内 SC 字族通常 index 2；
需要项目字体时自行放回 `fonts/`。在线字体只用于 HTML 介质，转曲（M2）必须用本地等价字体。

## 与字体组合的关系

先选 T01–T32 定字形气质，再选 M1–M6 定呈现介质。

| 字体组 | 推荐介质 | 推荐手法 |
| --- | --- | --- |
| T01 硬朗 | M2 | 超粗压边、裁切出血 |
| T02 文学宋 | M1 / M2 | 细体大字、竖排 |
| T03 高定细黑 | M2 | 描边镂空、金属渐变 |
| T04 粗野 | M2 | 叠印偏移、裁切出血 |
| T05 杂志 | M2 | 金属渐变、单字旋转 |
| T09 暗调 | M2 | 描边镂空、材质填充 |
| T10 楷体 | M4 / M1 | 书法、印章反白 |
| T12 现代宋 | M1 / M2 | 细体大字、局部描边 |

## 印刷注意

- M2 转曲是矢量，最安全；描边不要低于 1.5px（成品尺寸）。
- M4 图片填充分辨率 ≥ 300dpi；深色文字填充需确认暗部不糊。
- M5 裁切要留 3mm 出血，且关键笔画不能落在裁切线外。
- 金属渐变用四色模拟时，避免脏黄；有条件用专金。
- M3 Canvas 必须导出高分辨率 PNG，不能直接打印 Canvas。

## 反模式

- 整张封面三种以上文字介质同时出现。
- 金色渐变 + 超粗字 + 阴影 + 描边全叠在一起，油腻。
- 描边字用在浅底上，失去层次。
- 材质填充的图片本身很暗，字读不出来。
- 裁切把关键字切成无法辨认的残片。
