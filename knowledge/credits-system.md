# 署名与出版信息：辅助文字也要设计

> 题眉、作者、组编、出版社加起来通常不到版面 8%。
> 这 8% 最容易变成模板：分类小字孤悬左上，作者左下，社标右下，四角各放一点。
> 换位置不等于做设计。真正要解决的是：这些字和标题、和主视觉，发生什么关系。

本文件只给五种有结构理由的原型。每种都说明「它靠什么成立」，不成立就别用。

## 一、先定关系，再选原型

按顺序回答，不要先挑样式：

1. **主视觉是不是满版出血？** 是 → A03 图文咬合。满版图上再加一条底栏，等于在图上贴了一张纸条。
2. **书名是否居左、信息型？** 是 → A02 标题同轴。署名与标题共用一条轴线，信息成组。
3. **题材是否文学、诗、传记、传统文化？** 是 → A04 书脊竖排。竖列与标题边缘平行。
4. **是否档案、复古、独立出版，且画面有安静侧边？** 是 → A05 题签。实底贴边，像一条批注。
5. **以上都不是** → A01 底栏。它是默认解，但要把基线和间距做对。

一条硬判断：**署名区只允许存在一个视觉焦点**。作者名、社标、题眉三者中，只能有一个明显更重。两个以上就散。

## 二、五种原型

### A01 底栏对齐

作者贴左，社标贴右，同一条基线。

- 成立条件：封面底部是干净的纯色区或留白区。
- 要做对的：作者名与社标底边对齐；作者名比社标中文名大 25–35%；去掉作者名前那条没有分隔功能的短线。
- 不成立：底栏压在图上、底栏与副标题抢同一行、三套候选全用它。
- 参数：作者 1.9cqw / 700，机构 1.45cqw / 400，社标高 4.4cqh；距底 1.15sy。

### A02 标题同轴

作者、机构、出版社合成一行信息带，与标题共用左边缘或中轴。

- 成立条件：标题本身是齐左或居中的信息型排版。
- 要做对的：整行宽度不超过标题宽度的 1.1 倍；分隔用中点或短竖线；社标压在行尾，不另起一行。
- 不成立：标题是满幅大字或图形字，同轴会变成第三条横线。
- 参数：姓名 1.35cqw / 500，机构 1.15cqw，社标高 2.8cqh；距底 1.2sy。

### A03 图文咬合

署名跨在主视觉下缘，一半在图上，一半落在底色，用整宽渐变把图与字连起来。

- 成立条件：主视觉满版或大半版，画面下缘有可压暗的区域。
- 要做对的：渐变从底边连续升起，高度 14–20% 画布，不能出现矩形边界；署名和社标同基线。
- 不成立：主视觉本身很亮或很碎，压暗后仍读不清；这时换 A01，不要硬压。
- 参数：scrim `--credits-scrim`，灰度对比 ≥4.5:1。

### A04 书脊竖排

署名列竖排贴侧边，社标保持水平放在竖列末端。

- 成立条件：文学、诗、传记、传统文化；标题本身留出侧边空白，竖列与标题边缘平行。
- 要做对的：竖列距边 1.1 倍安全边距；字距 0.14em 以上；社标不旋转。
- 不成立：商业书、货架书、标题已经占满宽度；竖排会变成一条黑边。
- 参数：姓名 1.9cqw，机构 1.25cqw，社标高 3.4cqh。

### A05 题签印戳

作者与社标收进一个有实底和边框的小竖块，贴在侧边，像档案标签。

- 成立条件：档案、复古、独立出版、限量版；画面有安静的侧边区域。
- 要做对的：实底颜色取自画面已有颜色；边框与封面线宽体系一致；块宽不超过 22% 画布；贴近侧边但保留 1.1 倍安全边距，不悬浮在画面中央。
- 不成立：画面没有安静区域；题签会变成贴在脸上的价签。
- 参数：内边距 ≥1.8cqw；不加投影、圆角、渐变。

### 选型速查

| 内容类型 | 首选 | 次选 | 不要用 |
| --- | --- | --- | --- |
| 报告 / 白皮书 | A02 | A01 | A05 |
| 商业方法书（气质轨） | A01 | A03 | A05 |
| 商业书（货架轨） | A01 | A03 | A04 |
| 文学 / 诗集 / 传记 | A04 | A01 | A02 |
| 艺术 / 摄影 / 画册 | A03 | A01 | A02 |
| 档案 / 复古 / 独立出版 | A05 | A04 | A02 |

## 三、题眉不能孤悬

题眉单独占一个角，是截图里最常见的问题。三条归位规则：

1. **和标题或署名同区。** 书籍封面默认并入署名信息带（`--kicker-pos inline`），位于署名上方 1–2 个字号的距离；报告随布局，与标题同轴；文学可用竖排贴书脊（`side`）。
2. **不和署名抢同一个角。** 题眉在左上，署名也在左上附近时，两者必须形成上下层级，不能各说各话。
3. **不做无功能的装饰。** 色带、序号、几何标记只在系列本身有编号体系时使用，否则就是给空白找事做。

`--kicker-pos auto` 的默认行为：书籍画布（book / pub34 / story）用 `inline`，其余跟随布局。不要为了“看起来不一样”随手改成 `topright`。

## 四、署名怎么写

1. **角色词按真实身份。** 著 / 编著 / 主编 / 绘 / 译 / 口述 / 整理，角色词字号降 20–30%，紧贴姓名右侧。
2. **多作者分主次。** 第一作者 700，其余 400，用「、」连接；超过三位写「XXX 等」。
3. **机构作者优先。** 课程书、企业书的署名主体是机构时，机构名做主，个人名做副。
4. **姓名可断行。** 双行、竖排、姓名与角色上下排都合法，阅读顺序不能变。
5. **英文作者双行。** 中文名在上，原名在下，原名小一号。
6. **卷次单独成块。** 「第 X 卷」「全 X 册」做成小方块或竖排标签，不塞进底栏。

## 五、美观判据

排版做完，用这八条自查。任何一条不满足，先改结构，不要加装饰：

1. **一条主轴。** 标题、署名、题眉三者中至少两者共用一条轴线。
2. **留白成块。** 辅助文字集中在 1–2 个区域，不把空白切成碎片。
3. **重量顺序。** 书名 > 副标题 > 作者 > 题眉 > 社标，不出现作者比副标题重、社标比题眉重。
4. **社标不孤立。** 社标要么与署名同基线，要么在信息带末端；不单独漂在一个角。
5. **小字不撒点。** 画面四角最多出现两个信息点，多于两个就是撒胡椒面。
6. **缩略图稳。** 240px 下辅助文字退成一条灰带，整体重心不散。
7. **离边有余量。** 辅助文字距底 ≥1.1 倍安全边距（`1.15sy`），侧边与标题左边缘同宽；贴边不算合规，只是没越界。
8. **差异有理由。** 能用一句话说清「这套为什么这样排」，说不清就是为不同而不同。

## 六、三套候选的差异规则

- 至少覆盖两种署名原型。
- 差异要来自结构关系（底栏 / 同轴 / 咬合 / 竖排 / 题签），不是字号或位置微调。
- 题眉位置至少一套与另外两套不同，且仍满足归位规则。
- 三套里最多一套使用 A01，其余必须给出选型理由。

## 七、反模式

1. **题眉孤悬左上或右上**，与标题、署名都没有关系。
2. **为不同而不同**：把社标挪到对角、把署名缩到看不见、把作者名放大成图形，却没有结构理由。
3. **四角撒点**：题眉左上、作者左下、社标右下、卷次右上。
4. **角色词批发「著」**：主编、绘者、译者都写成著。
5. **社标压图无底**：放在复杂图像上，读不清。
6. **署名比副标题重**：作者字号超过副标题。
7. **题签悬浮在画面中央**：标签不像标签，像贴纸。
8. **竖排字距过密**：远看是一条墨线。
9. **辅助文字侵入 5.5% 裁切风险区**。
10. **用旋转社标表达创意**：社标必须水平，创意放在承载方式和位置上。

## 八、检查清单

- [ ] 三套候选覆盖至少两种原型，差异能一句话说清。
- [ ] 题眉与标题或署名同区，画面四角的信息点不超过两个。
- [ ] 署名区只有一个视觉焦点，作者、社标、题眉有明确重量差。
- [ ] 作者角色词与真实身份一致。
- [ ] 社标尺寸满足轨道要求（商业书 ≥22% 画布宽），压图时有 scrim 且灰度对比 ≥4.5:1。
- [ ] 辅助文字不进入 5.5% 裁切风险区。
- [ ] 240px 缩略图下署名区不抢书名，社标仍可识别。
- [ ] 竖排文字阅读顺序正确，标点与数字方向无误。
- [ ] 去掉任何一个装饰元素，信息仍然完整。
