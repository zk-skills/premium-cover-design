# 跨风格组合方案（18 套）

前面 26 套是基础配方。混合风格用于覆盖普通风格难以处理的主题：主风格决定调性与秩序，辅助风格只提供一个明确的手法或媒介，不做平均混合。

H01-H12 来自原始设计配方文档；H13-H18 为在原表基础上补充的扩展组合，补齐科技与人文、建筑与档案、数据与纪实、植物与科学、财经观点、科学传播六类缺口。

每套组合都带可执行手法，用 `tools/generate_cover.py --hybrid Hxx` 可直接产出成品：
主风格提供色板与版式骨架，辅助风格按需提供主视觉手法 / 纹理 / 展示字体，组合自带推荐布局。

## 使用示例

- **H01 Literary Science**（日式文学 + 科学插画）：Literary Science。用一张具有科学绘图质感的花苞插画，搭配日式文学留白。
- **H02 Cinematic Swiss**（瑞士编辑 + 电影摄影）：Futuristic Editorial。以抽象 3D 智能网络为主体，使用瑞士编辑网格组织标题。
- **H03 Archival Brutalism**（档案美学 + 粗野主义）：Luxury Surrealism。一个漂浮的古老钟表，搭配象牙白背景和高反差衬线标题。
- **H04 Luxury Surrealism**（极简奢华 + 超现实主义）：Archival Brutalism。老城市照片叠加超大粗体标题和档案编号。
- **H05 Botanical Modernism**（植物艺术 + 现代主义）：Conceptual Botanical。植物枝叶与数据节点融合，但保持自然摄影的质感。
- **H13 Tech Poetic**（科技编辑风格 + 诗意极简）：以诗意极简的疏朗留白承载科技编辑的冷峻三维结构，适合技术与人文交叉的主题。
- **H14 Archival Architectural**（历史档案美学 + 建筑现代主义）：档案美学的旧纸与编号，配建筑现代主义的透视结构，适合城市空间的历史叙事。
- **H15 Data Documentary**（数据智能风格 + 电影摄影）：数据智能的节点网络压在电影摄影的明暗层次之下，适合既要有数据又要有人在场的内容。
- **H16 Botanical Scientific**（植物艺术 + 科学插画）：植物艺术的标本线稿与科学插画的解剖标注结合，用于可被查阅的自然科普。
- **H17 Brutalist Finance**（瑞士粗野主义 + 金融研究风格）：粗野主义的强对比大字压着金融研究的精密图表，适合有明确立场的数据类内容。
- **H18 Risograph Scientific**（独立印刷艺术 + 科学插画）：独立印刷的套色错版承载科学插画的解剖线稿，用于降低科学内容的距离感。

## 调用方式

```bash
python tools/generate_cover.py --hybrid 13 \
  --title "机器之后的安静" --subtitle "当算法退场，人如何重新观看" \
  --kicker "人文观察" --meta1 "技术与人文实验室" --meta2 "2026" \
  --out cover.html
```
