## 现代出版与编辑设计

### 01. Swiss Editorial｜瑞士编辑主义

- **设计定位**：理性、现代、专业、精确。
- **风格释义**：设计指令： 强调网格秩序、非对称布局、明确的视觉层级。避免装饰性插画和过多渐变，让标题本身成为视觉主体。

| 设计维度 | 具体方案 |
| --- | --- |
| 风格描述 | 国际主义、现代主义、编辑设计 |
| 表现手法 | 大字号字体、几何色块、精细分割线、微型编号 |
| 布局方式 | 左对齐、非对称网格、模块化布局 |
| 构图方案 | 左侧标题、右侧主体；或标题与图形上下错位 |
| 字体 | 思源黑体、Helvetica 类无衬线、等宽字体 |
| 色彩 | 暖白、黑、朱红；或深蓝、灰白 |
| 材质 | 纯色、轻微纸纹、平面矢量 |
| 适合方向 | 商业报告、科技文章、研究报告、知识出版物 |

**设计令牌**：底色 `#F4F1EA` · 主墨色 `#111111` · 强调色 `#D62828` · 辅助色 `#6B6B6B` · 纹理 `paper`

**参考示例**

- 《人工智能时代的知识革命》 超大黑体标题，右侧放置红色几何抽象结构，底部以微型文字标注研究机构和出版日期。
- 《2026 全球数字经济发展报告》 采用模块网格，将报告名称、年度、行业分类和抽象数据图形组织成严谨的信息体系。
- 《实践与认知》 白色背景、黑色大标题、一个偏离中心的红色几何圆形，表达实践与认知之间的关系。

> **AI 设计指令**：强调网格秩序、非对称布局、明确的视觉层级。避免装饰性插画和过多渐变，让标题本身成为视觉主体。

### 02. Contemporary Editorial｜当代编辑设计

- **设计定位**：时尚、成熟、内容感强。
- **风格释义**：设计指令： 像专业杂志主编一样组织视觉信息，强调摄影质量、文字与图像的关系，以及画面节奏。

| 设计维度 | 具体方案 |
| --- | --- |
| 风格描述 | 高级杂志、现代出版、文化编辑 |
| 表现手法 | 摄影、超大标题、局部遮挡、图片裁切 |
| 布局方式 | 满版图片、左右分栏、标题叠加 |
| 构图方案 | 图片占据主要区域，标题沿边缘或留白区布局 |
| 字体 | 现代衬线 + 无衬线 |
| 色彩 | 根据摄影主体选择，辅助色不超过两种 |
| 材质 | 高清摄影、轻微胶片颗粒 |
| 适合方向 | 文化、科技、商业、人物、深度文章 |

**设计令牌**：底色 `#F3F2EF` · 主墨色 `#171717` · 强调色 `#B8412E` · 辅助色 `#7C7A74` · 纹理 `grain`

**参考示例**

- 《重新认识人工智能》 一张具有空间感的抽象科技摄影，超大标题跨越画面边缘。
- 《城市的另一面》 建筑摄影占据整页，标题置于左下角，右上角放置小型期刊编号。
- 《人与自然》 人物与自然环境形成视觉对照，标题与人物轮廓局部重叠。

> **AI 设计指令**：像专业杂志主编一样组织视觉信息，强调摄影质量、文字与图像的关系，以及画面节奏。

- **风格释义**：设计指令： 用最少的元素表达最明确的概念，避免把极简理解成简单的白底加黑字。

**参考示例**

- 《复杂系统》 通过大小不同的几何圆形建立系统关系，使用单色调表现复杂与秩序。

- 《知识的结构》 多个透明几何体相互嵌套。
- 《无限可能》 一条连续的金属带形成无限循环结构。
- 《复杂性的美》 由无数细小结构构成一个完整的抽象雕塑。
- 分析内容
- 选择艺术方向
- 确定视觉隐喻
- 选择构图与布局
- 配置视觉语言
- 生成三个不同方向
- 生成 HTML 并审查
- 主风格必须明确，不能把多个风格平均混合。
- 视觉隐喻优先于对主题的字面插画。
- 标题和主体必须有明确的主次关系。
- 字体、色彩、材质应当服从整体艺术方向。
- 不能为了表现设计感而添加无意义的英文、编号和装饰。
- 相同内容允许不同艺术方向，但不同方案必须有明显的构图差异。
- 不同主题不能机械套用相同布局。
- 设计必须考虑中文标题的实际长度。
- 所有图片与文字必须保持清晰的空间关系。
- 优先保证视觉完整性，而不是堆砌设计元素。
