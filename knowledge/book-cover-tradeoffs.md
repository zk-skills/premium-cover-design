# 商业书封面的双轨模型与案例对照

> 同样一本商业书，可以做成「气质轨」也可以做成「货架轨」。两者都成立，但阈值不同。
> 用一套标准评判两轨，会把货架轨判成「标题过大」，把气质轨判成「不够抓眼」。
> 本文件给出判定方法、2×2 标题规则、暖色渐变规则和八维对照表。

## 一、先判轨，再定版

| 维度 | 气质轨（Premium） | 货架轨（Shelf） |
| --- | --- | --- |
| 目标 | 建立作者专业性与品牌溢价 | 3 秒内被货架／信息流识别 |
| 典型渠道 | 地面店、礼品、课程、设计圈、专业机构 | 电商主图、机场店、商超、短视频 |
| 读者状态 | 已被推荐，愿意停留 30 秒 | 正在扫货，只给 3 秒 |
| 标题字高 | 短边的 12–22% | 短边的 26–40% |
| 标题墨量（字形覆盖） | 6–14% 版面 | 14–30% 版面 |
| 主副比 | ≥ 2.2 | ≥ 3.0，常见 5–8 |
| 构图 | 偏心、出血、图文对峙 | 居中或 2×2 方块，标题即主视觉 |
| 色彩 | 低饱和、深底或纸白、单一强调 | 高明度暖底、单一高饱和强调 |
| 主视觉 | 材质、摄影、结构隐喻 | 大字、几何光环、单一符号 |
| 字体 | 宋体、细黑、有笔锋 | 粗黑、粗圆、几何无衬线 |
| 风险 | 远看弱、渠道不认 | 像培训课、缺少溢价 |

**判定顺序**：渠道 → 作者知名度 → 定价 → 同类书陈列 → 读者决策时间。
渠道与决策时间冲突时，以决策时间为准。

**默认产出**：商业经管书至少做一套气质轨、一套货架轨。只做一套时，必须在 `notes.md` 写明轨道与依据。

## 二、2×2 标题网格

四字书名（如「三品合一」）的货架轨首选。

| 规则 | 做法 |
| --- | --- |
| 读序 | 严格按行从左到右：第一行前两字，第二行后两字。禁止竖列读法。 |
| 字格 | 四个等大方格，共用一套基线；字面大小一致。 |
| 字距 | 0.02–0.08em；字与字不接触，也不散成四个独立图标。 |
| 行距 | 0.98–1.08 倍字高；两行要咬合成一个方块。 |
| 末字「一」 | 可当横线用，但必须保留起收笔，不能被误读为分隔线。 |
| 与图形的关系 | 标题是主角时，不再放同等重量的第二主体；图形只做背景或小面积落款。 |
| 适用长度 | 4–6 字最佳；超过 6 字改用两行横排，不要硬凑方格。 |

**判定**：把封面缩到 240px 宽，若第一眼读不出四个字的顺序，网格失败。

## 三、暖色渐变与光晕

暖底（米白、杏、浅橙）适合增长、机会、正向情绪，但最容易做成培训课。

- 最多两个色相；第三个色相只能用在中性灰或文字黑上。
- 渐变必须有结构理由：两个圆相交＝合并，地平线＝增长，光晕中心＝聚焦。没有理由的粉橙渐变删掉。
- 底色明度跨度控制在 25 L* 以内，否则标题在一端会失去对比。
- 标题渐变的最浅处与底色对比仍要 ≥ 4.5:1；笔画末端不得淡到 30% 以下。
- 「粗圆字体 + 粉橙渐变 + 居中五段式」三者同时出现，视为培训课脸，至少去掉一项。

## 四、案例拆解：暖光 2×2 商业书

参考图：原 `references/cases/case-warm-2x2.png`（用户提供的对照案例，非官方出版文件；图片资产已移除以压缩体积）

| 项目 | 实测／观察 |
| --- | --- |
| 画布 | 520×743，比例 0.70，接近 180×257mm |
| 标题 | 2×2 方块，单字约画布宽的 38%，标题块约占宽 84%、高 54% |
| 标题字体 | 粗几何无衬线，笔画末端有圆角；字内有红到浅粉的渐变 |
| 底色 | 暖白 `#FBF3F1` 到浅杏 `#F0B7AC`，右侧更饱和 |
| 背景图形 | 两个大圆弧／圆面在标题后方相交，形成透镜状亮区 |
| 副标题 | 约画布宽的 5.4%，黑色粗体，居中 |
| 作者／组编 | 约 3.1%，居中，一行 |
| 宣传语 | 约 3.8%，红色，居中，单独一行 |
| 社标 | 约画布宽的 19%，居中置底 |
| 结构 | 标题、副标题、作者、宣传语、社标五段全部居中 |

### 值得借鉴（5）

1. **标题就是主视觉**：不依赖图片，四字放大到 38% 宽，货架识别极快。
2. **2×2 网格**：四个字组成一个方块，天然对应「合」，比单行更有体积。
3. **暖色光学**：两个圆相交的亮区，不解释也能感到「融合」，比箭头高级。
4. **销售信息有独立层级**：宣传语单独一行、用强调色，和作者行分开。
5. **社标置底居中**：在货架轨里比放角落更稳，适合系列书统一。

### 不应照搬（5）

1. **笔画渐变到接近白色**：细笔画在浅底上消失，远看缺笔。
2. **粗圆字体 + 粉橙渐变**：两者叠加会滑向培训课气质。
3. **五段全部居中且等距**：一旦标题不够大，就退化成默认三段式。
4. **背景光晕没有边界**：印刷时大面积浅渐变容易出现断层与墨杠。
5. **社标只有 19% 宽**：在电商缩略图里几乎不可读，至少 22–26%。

### 一句话结论

案例赢在「标题权重 + 暖色情绪 + 读序清楚」，输在「字体与渐变的工艺精度」。
照搬它的尺寸，不要照搬它的质感。

## 五、八维对照评分（每项 0–5）

对每个候选和参照案例各打一次，总分只用于比较，不用于绝对评判。

| 维度 | 5 分标准 |
| --- | --- |
| 3 秒首读 | 240px 缩略图下，书名与品类一眼可辨 |
| 标题权重 | 与轨道匹配：气质轨 12–22%，货架轨 26–40% |
| 货架差异 | 同品类陈列中，底色或图形能第一眼区分 |
| 溢价感 | 材质、字体、留白让人相信定价 |
| 概念独特性 | 去掉文字后，图形仍能指向主题 |
| 品类匹配 | 画面情绪与「增长／破局」不冲突 |
| 作者匹配 | 与作者身份、过往作品气质一致 |
| 渠道适配 | 目标渠道的尺寸、印刷、审读习惯都成立 |

**用法**：主推方案必须在「3 秒首读」与「溢价感」两项都不低于 3 分；若低于 3，换轨道重做，不要靠调色补救。

## 六、商业书附加检查（6 项）

在 12 项通用门禁之外，商业书加做：

| # | 检查 | 气质轨 | 货架轨 |
| --- | --- | --- | --- |
| B1 | 240px 缩略图书名高度 | ≥ 16px | ≥ 26px |
| B2 | 标题墨量（字形覆盖） | 6–14% | 14–30% |
| B3 | 主副字号比 | ≥ 2.2 | ≥ 3.0 |
| B4 | 居中堆叠 | 允许，但需有偏心元素 | 允许；若五段全居中，标题须 ≥ 30% 宽 |
| B5 | 社标宽度 | ≥ 18% 画布宽 | ≥ 22% 画布宽 |
| B6 | 渐变最浅处对比 | ≥ 4.5:1 | ≥ 4.5:1 |

## 七、决策树

```
商业书？
├─ 否 → 按原流程，不套本文件
└─ 是
   ├─ 渠道以电商主图／机场／商超为主？
   │   ├─ 是 → 货架轨：2×2 或压边大字，标题 26–40%，暖底或高对比底
   │   └─ 否 → 下一步
   ├─ 作者有强专业身份、定价偏高、渠道以推荐为主？
   │   ├─ 是 → 气质轨：偏心构图、材质／摄影、标题 12–22%
   │   └─ 否 → 两轨各做一套，按八维评分择优
   └─ 两轨都做时，共用同一套文案与社标，只换版式与色彩，便于比较
```

## 八、与现有评分脚本的关系

`tools/score_cover.py` 的标题权重一项原本按气质轨设定：12–26% 得满分，超过 26% 降分。
新增 `--track mass` 后，改为 26–40% 得满分；`--track auto` 按标题大小推断。
默认仍是气质轨，避免改变既有项目的结果。

`shelf_test.py` 生成 240px 与 120px 缩略图，并把平均明度、饱和度、暖色比例打出来，用于货架轨的首读检查。
