### R01 Swiss Editorial｜瑞士编辑主义

| 拆解项 | 内容 |
| --- | --- |
| 主体与标题的位置关系 | 左侧大标题与右侧几何主体分置，主体以色块与细线构成，底部微型文字横贯全宽 |
| 视觉媒介 | 平面矢量：几何色块、精细分割线、大字号字体 |
| 色彩体系 | 暖白底、纯黑字、单一朱红强调 |
| 为何适合该主题 | 报告类需要一眼建立「秩序与权威」，标题与主体各占一半版面即可形成清晰的阅读入口 |
| 值得借鉴 | 严格网格与微型编号的尺度对比；用单一强调色而不是多色 |
| 不应照搬 | 不要照搬具体的红色块比例与线距——应按自身标题长度重新定网格 |

### R02 Contemporary Editorial｜当代编辑设计

| 拆解项 | 内容 |
| --- | --- |
| 主体与标题的位置关系 | 满版摄影或大幅图占据主体，标题沿画面边缘或留白区排布，允许局部叠压 |
| 视觉媒介 | 高清摄影 + 超大标题 + 轻微胶片颗粒 |
| 色彩体系 | 由摄影主体决定主色，辅助色不超过两种 |
| 为何适合该主题 | 深度文章需要画面先建立情绪，文字只做定位而非说明 |
| 值得借鉴 | 标题与图片边缘的咬合关系（压住一点比完全分开更亲密） |
| 不应照搬 | 不要照搬摄影题材与色调——情绪要由自己的主题决定 |

### R03 Modernist Minimalism｜现代主义极简

| 拆解项 | 内容 |
| --- | --- |
| 主体与标题的位置关系 | 单一几何主体偏离中心，标题以小字号衬线落在角落，留出大面积空白 |
| 视觉媒介 | 几何图形、单色块、精细线条 |
| 色彩体系 | 黑白灰为主，米白底配单一强调色 |
| 为何适合该主题 | 哲学与思想类封面需要「让读者停下来」，空比满更有说服力 |
| 值得借鉴 | 极小主体与巨大负空间的比例关系（主体通常不超过版面 25%） |
| 不应照搬 | 不要把「极简」理解成白底黑字——没有几何主体的极简是空洞 |

### R04 Swiss Brutalist｜瑞士粗野主义

| 拆解项 | 内容 |
| --- | --- |
| 主体与标题的位置关系 | 超大标题本身成为主图形并被裁切或压过，红色矩形切割标题区域 |
| 视觉媒介 | 超粗字体、硬阴影、色块、裁切 |
| 色彩体系 | 黑白为主，红或黄作为唯一冲击色 |

| 不应照搬 | 不要滥用裁切——裁切必须与栅格对齐，否则是事故不是设计 |
