# 装饰细节规范

封面上的「装饰」是装饰，不是设计。以下规则约束它能做什么、不能做什么。

## 一、允许的装饰

| 装饰 | 用法 | 归属配方 |
| --- | --- | --- |
| 微型编号 | 与标题形成尺度对比，字号通常小于标题的 1/8，字距 +0.08em | R01 瑞士编辑主义、R05 模块化编辑设计 |
| 精细分割线 | 1px 细线，用于分隔信息区或建立栅格基线 | R01、R05、R12、R13 |
| 几何色块 | 单一强调色，形状为矩形、圆或斜切，面积 ≤ 版面 15% | R01、R04、R17 |
| 网格与坐标 | 极低对比度，作为背景结构而非图案 | R05、R15、R16 |
| 档案标签与印章 | 与历史、文献类主题绑定 | R23 档案美学、R24 科学插画 |
| 纸纹与印刷噪点 | 透明度 4%–14%，不破坏纯色块 | 全部带纹理档位的配方 |
| 套色错版 | 印刷工艺模拟，偏移量在 2–5px | R19 独立印刷艺术 |

## 二、禁止的装饰

1. **无意义的英文与编号**：`VOL.01`、`ISSUE 07`、`THE FUTURE OF...` 这类与内容无关的标签，会被门禁第 6 项判为失败。
2. **无信息量的图标**：装饰性图标只会稀释字体表现。
3. **渐变与发光**：与配色体系冲突，且印刷不可控。配方中的 `grain` / `rough` / `print` 纹理是例外。
4. **超过三种字重**：封面层级由字号、字重、颜色三者共同控制，超过即乱。
5. **圆角与投影堆叠**：仅在 R08 分层拼贴等明确需要空间感的布局中使用。

## 三、装饰的量级参考

| 项目 | 建议值 |
| --- | --- |
| 强调色面积 | ≤ 版面 15% |
| 装饰性元素数量 | ≤ 3 类 |
| 分割线粗细 | 1px（成品尺寸下） |
| 微型编号字号 | 1.2–1.6cqw |
| 纹理不透明度 | 4%–14% |
| 套色错版偏移 | 2–5px |

## 四、装饰与栅格的关系

装饰必须服从栅格，不允许「差不多对齐」：

- 装饰元素的基线与标题基线对齐，或与其成明确的整数倍关系。
- 斜切、多边形裁切的斜率与版面对角线一致。
- 分层拼贴的旋转量控制在 2–4 度，阴影方向与光源一致。
- 框景构图的内框留白是外框留白的整数倍。
