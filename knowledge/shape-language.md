# 形状语言：不要默认所有元素都是矩形和直线

> 直角、矩形、水平线是安全的，也是最容易让封面变成模板的。
> 形状不是装饰，它先于文字传达情绪：硬边说秩序，曲线说流动，撕裂说冲突，圆说聚合。

## 一、三种形状语言

| 语言 | 词汇 | 情绪 | 适用 |
| --- | --- | --- | --- |
| 几何 | 直角矩形、正圆、等边三角、45° 斜线、严格网格 | 秩序、理性、权威 | 报告、数据、学术、机构 |
| 有机 | 手绘曲线、流体、墨迹、水渍、烟、丝带、织物褶皱、撕裂纸边、烧灼边 | 生长、冲突、温度、偶然 | 商业方法、社会议题、文学、品牌故事 |
| 混合 | 硬边标题 + 曲线主视觉；几何网格 + 一处手绘；材质实拍 + 非正交裁切 | 张力、当代、可读性兼得 | 大多数商业书 |

**原则**：一张封面最多两种形状语言。三种以上会失焦。

## 二、非正交的八种做法

1. **轻微旋转**：主视觉或色块旋转 3–8°。超过 10° 会像事故，低于 2° 看不出来。
2. **弧形／椭圆裁切**：用圆、椭圆、拱形切开摄影或色块，替代矩形窗口。
3. **斜切**：一条 15–75° 的斜线把版面分成两块，标题压在斜线上或避开。
4. **撕裂／烧灼边**：纸、布料、胶带的真实边缘，适合冲突、破局、手工感。
5. **流体／墨迹**：不规则色块承担「生长、渗透、融合」，边缘要有控制，不能像随机污渍。
6. **弯曲基线**：标题沿弧线排，字号不变、字距微调；只适合短标题。
7. **透镜／相交**：两个圆或两个形体相交，交叠区提亮或换色，表达「合」。
8. **出画与透视**：主体被画布边缘切掉一部分，或用俯视／低视让矩形产生梯形。

## 三、使用规则

1. 至少有一个非正交或有机元素。主题明确要求严格网格（如年鉴、法律文本）时，在 `notes.md` 写明理由。
2. 非正交元素不能侵入标题安全区，不能改变阅读顺序。
3. 每个曲线或斜切要有功能：指向、包裹、分割、合并、承托。找不到功能的删掉。
4. 形状语言要与材质一致：金属可以硬边，纸张可以撕裂，液体可以流动，石材不宜像橡皮。
5. 硬边标题与有机主视觉形成对比；标题也做曲线时，主视觉要收敛。
6. 不要为了「不规矩」而旋转文字。社标必须水平；署名可竖排（A02/A05/A08），但只在文学、档案、艺术方向使用，并保证阅读顺序。见 `credits-system.md`。

## 四、主题映射

| 主题 | 建议形状 | 避免 |
| --- | --- | --- |
| 增长、机会 | 上升弧、开口曲线、向外扩散的同心弧 | 直线箭头、火箭 |
| 破局、内卷 | 斜切、撕裂、突破边界的形体 | 无意义的爆炸形 |
| 合一、整合 | 相交圆、透镜、咬合形体、共用边 | 三个圆简单并排 |
| 高端、工艺 | 大面留白 + 一条精确曲线，或完整几何体 | 过多手绘 |
| 文学、情绪 | 墨迹、水渍、柔焦边缘、不规则纸张 | 硬边色块堆叠 |
| 科技、数据 | 规则网格 + 一处非规则扰动 | 全是发光线条 |

## 五、反模式

1. 所有元素都是矩形、水平线、直角，没有任何曲线或斜线。
2. 旋转没有参照轴，像文件放歪了。
3. 圆角矩形当万能药，每个信息块都加圆角。
4. 手绘线抖得没有控制，像草稿。
5. 有机形状只做背景装饰，与主题无关。
6. 为了不规则把标题、署名也倾斜，阅读成本上升。

## 六、检查清单

- [ ] 画面里至少有一个非正交或有机元素。
- [ ] 这个元素有明确功能，不是装饰。
- [ ] 形状语言不超过两种。
- [ ] 标题、副标题、署名、社标的阅读轴没有被破坏。
- [ ] 形状与材质、主题一致。
- [ ] 缩到 240px 后，形状仍然能看出意图，而不是一团噪点。

## 七、决策卡模板

```
形状语言：几何 + 有机（主：相交圆；辅：硬边标题）
非正交手法：两圆相交的透镜区 + 主视觉旋转 4°
功能：透镜区承托标题，表达「合」
约束：标题保持水平；透镜不进入 5.5% 安全区
放弃的方案：全矩形网格（太像报告）、整幅旋转 12°（读序被打断）
```
