# 图像与标识清晰度：印刷前必须算出来的数

> 清晰度不是「看起来还行」。它由源像素、成品显示尺寸和放大倍数决定。
> 屏幕上的 100% 预览会骗人，付印前的有效 dpi 不会。

## 一、三个公式

```
有效 dpi = 源像素宽 ÷ (成品显示宽 mm ÷ 25.4)
放大倍数 = 画布显示宽（CSS px） ÷ 源像素宽
所需像素 = 成品显示宽 mm ÷ 25.4 × 目标 dpi
```

示例：1600px 的图，成品上显示 141mm 宽。
有效 dpi = 1600 ÷ (141 ÷ 25.4) = 288dpi。低于 300，属于「接近下限」。

## 二、阈值

| 素材 | 印刷最低 | 理想 | 屏幕最低 | 说明 |
| --- | --- | --- | --- | --- |
| 主视觉摄影／合成图 | 300dpi | 350dpi | 150dpi | 大幅面海报可降到 200dpi，观看距离远 |
| 出版社 Logo | 600dpi 等效 | 矢量 | 300dpi | 优先 SVG / PDF / EPS |
| 作者头像、小图 | 300dpi | 350dpi | 150dpi | 不要从网页截图 |
| 纹理、纸纹 | 300dpi | 350dpi | 150dpi | 无缝纹理需检查接缝 |
| 文字 | 不适用 | 矢量或 HTML | 矢量或 HTML | 不把正文做成图片 |

**放大倍数**：

| 倍数 | 判定 |
| --- | --- |
| ≤ 1.0 | 安全（缩小或原尺寸） |
| 1.0–1.5 | 可接受，检查边缘 |
| 1.5–2.0 | 警告，付印前打样 |
| > 2.0 | 不接受，重出或改版 |

## 三、Logo 的额外规则

1. 优先向出版社／品牌方索取矢量文件（AI、EPS、PDF、SVG）。
2. 位图 Logo 至少 600dpi 等效，且不得放大超过 2×。
3. 深底反白时检查笔画边缘：细线容易发灰、糊边。
4. 不要把 Logo 从网页截图后放大；不要用 JPG 的 Logo（白底会有方块）。
5. 透明 PNG 要检查半透明边缘，印刷时可能出现白边。
6. Logo 四周留出至少 0.5 倍标志高度的净空。

## 四、常见失败

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| Logo 边缘发毛 | 位图放大、JPG 压缩 | 换矢量或重出高分辨率 |
| 图片有颗粒／色块 | 多次压缩、低分辨率 | 找原图，重新导出高质量 |
| 深底反白字变细 | 油墨扩散 | 字重加一档，或改用浅底 |
| 透明边缘有白线 | 半透明像素 | 在纯色底上重新合成 |
| 纹理出现重复接缝 | 平铺纹理太小 | 扩大纹理或做镜像接缝 |
| 小字印刷糊 | 字号低于 6pt | 放大字号或删信息 |

## 五、处理顺序

1. **找原始文件**：相机原图、设计源文件、品牌方矢量。
2. **矢量重绘**：Logo、图标、简单图形优先重绘。
3. **按成品尺寸重出**：用「所需像素 = mm ÷ 25.4 × 目标 dpi」倒推。
4. **裁切，不拉伸**：改变构图用裁切，不用非等比缩放。
5. **适度锐化**：只在缩小后做一次轻度锐化，不要反复处理。
6. **打样**：细线、反白字、深色大面积必须打样。

## 六、工具

```bash
# 主视觉：成品显示 141mm
python tools/check_image_quality.py hero.png --mm 141 --display-px 1060

# Logo：成品显示 50mm，按标识标准
python tools/check_image_quality.py logo.png --mm 50 --display-px 374 --logo

# 多张一起算
python tools/check_image_quality.py a.png b.png --mm 141,50 --display-px 1060,374
```

输出：源像素、有效 dpi、放大倍数、结论。`fail` 项付印前必须处理，`warn` 项需打样确认。
