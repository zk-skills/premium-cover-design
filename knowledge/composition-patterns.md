# 布局与构图方案独立索引（16 套）

布局与风格解耦，可自由组合。

| ID | 名称 | 说明 |
| --- | --- | --- |
| L01 | 非对称网格 | 标题与视觉主体分置不同区域，利用空间比例建立秩序。 |
| L02 | 中心对称 | 标题与核心主体沿中心轴排列，适合庄重、正式主题。 |
| L03 | 超大标题 | 标题本身成为图形元素，允许局部裁切。 |
| L04 | 极限留白 | 少量元素与大面积空间形成强烈比例关系。 |
| L05 | 满版摄影 | 图像占据全部画布，文字在安全区域叠加。 |
| L06 | 分割布局 | 左右或上下分区，适合对比、分类、主题并列。 |
| L07 | 模块网格 | 使用规则模块分配标题、图片和信息。 |
| L08 | 分层拼贴 | 通过多层图像、纸片和文字构成空间。 |
| L09 | 框景构图 | 使用窗口、边框和局部框架引导视线。 |
| L10 | 对角线构图 | 利用斜线建立动势，适合科技和创新主题。 |
| L11 | 放射式构图 | 以中心向四周扩散，适合系统、网络、宇宙。 |
| L12 | 纵向排版 | 通过纵向文字、主体和空间形成阅读节奏。 |
| L13 | 图文重叠 | 让文字与图像产生前后层次关系。 |
| L14 | 碎片化构图 | 主体被拆分成多个不连续区域，制造视觉悬念。 |
| L15 | 孤立主体 | 通过单一物体和背景之间的关系建立视觉隐喻。 |
| L16 | 重心偏置 | 将视觉主体放在顶部、底部或一侧，形成不对称张力。 |
